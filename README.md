# 🤖 AgentKit — Build AI Agents in 100 Lines of Code

**6 production-ready AI agent templates** for OpenAI, Anthropic, and Vercel AI SDK.

[![Buy on Gumroad](https://img.shields.io/badge/Buy%20on-Gumroad-pink?style=for-the-badge)](https://zeoland.gumroad.com/l/agentkit)

## 📦 Included Templates

| Template | Description | Lines |
|---|---|---|
| Research Agent | Web search + summarize + cite sources | ~60 |
| Customer Support Bot | FAQ handling, escalation, sentiment tracking | ~70 |
| Code Reviewer | PR diff review, suggestions, bug detection | ~50 |
| Data Analyst | Natural language → SQL → visualization | ~65 |
| Content Writer | SEO blog posts with outlines | ~55 |
| Multi-Agent Orchestrator | Route tasks between specialized agents | ~80 |

## 🛠 Tech Stack

- Next.js 15 + TypeScript
- Tailwind CSS 4
- Vercel AI SDK compatible
- OpenAI / Anthropic ready

## 🚀 Quick Start

```bash
npm install
npm run dev
open http://localhost:3000
```
